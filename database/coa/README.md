# План счетов — рабочие материалы (черновик)

Источник: файл, присланный пользователем (`старый+новый`, физически «Лист6» в
исходной книге Excel) — таблица перехода со старой (советской) нумерации
счетов на План счетов Туркменистана по НСФО.

## Файлы

### `turkmenistan_chart_of_accounts.csv`

441 уникальный счёт. Колонки:

- `code` — код счёта НСФО, только цифры (для БД/ключей).
- `code_display` — тот же код в исходном написании с пробелами
  (например, «6111 41 00») — для отображения человеку.
- `name` — наименование счёта.
- `account_type` — Активы / Обязательства / Капитал / Доходы / Расходы /
  Забалансовые счета. **Определено автоматически** по первой цифре кода
  и, для кода «6», по категории (2-я цифра): категория 63 = Обязательства,
  61/62 = Активы.
- `category`, `subcategory`, `group`, `synthetic` — уровни иерархии кода
  (2/3/4/6 цифр соответственно) — для построения дерева счетов.
- `old_code` — старый (советский) номер счёта, если был указан в
  исходнике — для справки бухгалтеру, привыкшему к старой нумерации.
- `code_length` — длина кода в цифрах: 8 = аналитический (обычно
  проводимый) счёт, короче (4 или 6) = счёт-группа верхнего уровня без
  детализации в исходнике.

### `needs_manual_review.csv`

17 старых счетов, которым в исходнике сопоставлено **не одно**, а
несколько возможных новых кодов (например, «Расчеты с покупателями и
заказчиками» → `6218` или `6228`, в зависимости от ситуации), либо
пометка «разные» без конкретного кода. Эти позиции **нельзя** свести к
одному счёту автоматически — нужно решение бухгалтера по каждому
конкретному случаю (или явное правило, когда какой из вариантов
использовать).

## ⚠️ Важная оговорка — правьте `account_type`

Автоматическая классификация по коду **не идеальна**. Обнаружил как
минимум один явный случай: код `6218` (категория 62, по правилу должен
быть «Активы») называется «Договорные обязательства» — то есть по
смыслу это обязательство, а не актив. Категории 62/63 в этом плане
счетов, похоже, не строго разделены на «активы» и «обязательства» —
внутри них могут быть и дебиторская, и кредиторская задолженность.

**Прежде чем это станет основой таблицы `accounts` в БД (Этап 2),
пожалуйста, просмотрите (или отдайте бухгалтеру) колонку `account_type`
в `turkmenistan_chart_of_accounts.csv` и поправьте, где не совпадает
с реальным экономическим смыслом счёта.** Это разовая сверка примерно
на 440 строк — от неё зависит, правильно ли будут вести себя дебет/кредит
во всей системе.
