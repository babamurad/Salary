💼 Payroll System (Учет заработной платы и кадров)
Современное десктопное приложение для автоматизации кадрового учета и расчета заработной платы малых и средних предприятий.

Программа разработана на Delphi (RAD Studio) с использованием локальной базы данных SQLite. Она не требует сложной установки серверов, работает мгновенно и полностью портативна (Zero-install) — достаточно просто скопировать папку на любой компьютер с Windows.

(Добавьте сюда скриншот вашего красивого дашборда)

✨ Основные возможности
📊 Современный Дашборд: Наглядный главный экран в стиле Flat Design с ключевыми метриками (штат, ФОТ), уведомлениями о днях рождения и отсутствующих сотрудниках.

👥 Управление персоналом: Ведение подробных карточек сотрудников (ФИО, должность, отделы, оклад). Поддержка "мягкого удаления" (перевод в статус "Уволен") для сохранения исторической целостности расчетов.

💰 Умный расчет начислений: Автоматический расчет отпускных и больничных на основе истории выплат и стажа работы (настраиваемые проценты выплат в зависимости от выслуги лет).

📄 HTML-отчетность (Печать): Генерация красивых расчетных листков и зарплатных ведомостей с использованием веб-технологий (движок Edge/WebView2 + CSS Bootstrap). Готово к выводу на печать или сохранению в PDF.

⚙️ Гибкие настройки: Пользователь на лету может менять ставки налогов, удержаний и коэффициенты прямо из интерфейса программы, без изменения кода.

🔒 Безопасность: Встроенный экран авторизации с возможностью смены пароля администратора.

🧳 Многофирменный учет и Портативность: Программа и база данных хранятся в одной папке. Для ведения новой компании достаточно создать копию чистой базы данных .db.

🚀 Для пользователей: Как начать работу (Без установки)
Вам не нужно быть программистом, чтобы использовать эту систему! Программа полностью портативна (Zero-install).

Перейдите в раздел Releases (Релизы) справа на этой странице.

Скачайте последний архив Salary_Release.zip.

Распакуйте папку на вашем компьютере или на флешку.

⚠️ КРИТИЧЕСКИ ВАЖНО: Путь к папке с программой должен содержать только латинские буквы (английский алфавит) и не содержать пробелов! Драйвер базы данных не умеет читать кириллицу в путях.

❌ Неправильно: C:\Users\Иван\Рабочий стол\Зарплата

✅ Правильно: C:\Salary или D:\Apps\Salary

Зайдите в распакованную папку и запустите файл Salary.exe.

Пароль для первого входа по умолчанию: admin (настоятельно рекомендуется изменить его в меню "Настройки" -> "Безопасность").

Требования к системе: Windows 10 / 11. Для работы HTML-отчетов (ведомостей) в системе должен быть установлен Microsoft Edge WebView2 (встроен в современные версии Windows по умолчанию).

❗ Если при открытии отчёта появляется «Ошибка запуска WebView2»:

1. На компьютере не установлен (или повреждён) Microsoft Edge WebView2 Runtime — это отдельный компонент, который не всегда есть в старых/урезанных сборках Windows (LTSC, N-редакции, серверные ОС). Скачайте и установите "Evergreen Bootstrapper" с официальной страницы: https://developer.microsoft.com/microsoft-edge/webview2/

2. Программа скопирована в папку, куда у пользователя нет прав на запись (например, C:\Program Files). WebView2 создаёт рядом с Salary.exe кэш-папку EdgeCache и не может запуститься без прав на запись в неё. Перенесите папку с программой в место с полным доступом, например C:\Salary, либо запустите Salary.exe от имени администратора.

3. Путь к папке содержит кириллицу или пробелы — переместите программу в путь только из латинских букв, без пробелов (см. выше).

Начиная с этой версии программа показывает более подробное сообщение с кодом ошибки и вероятной причиной вместо общего «Ошибка запуска WebView2».

Проект открыт для доработок! Буду рад вашим Pull Requests (PR) и идеям по улучшению архитектуры.

Стек технологий
Язык/Среда: Delphi (Рекомендуется RAD Studio 11 Alexandria или новее, так как используются современные VCL-компоненты TStackPanel, TRelativePanel).

База данных: SQLite 3.

Компоненты БД: FireDAC.

Рендеринг отчетов: TEdgeBrowser (WebView2Loader.dll).

Как развернуть проект
Склонируйте репозиторий:

Bash

git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
Откройте файл проекта Salary.dproj в RAD Studio.

Убедитесь, что в свойствах проекта (Project -> Options -> Application -> Icons) установлена корректная иконка.

Для успешного запуска в папке с Salary.exe (в Win32\Debug или Win32\Release) должны находиться:

Папка database с файлом salarydb.db

Папка assets с файлом bootstrap.min.css (для стилизации отчетов)

Библиотеки sqlite3.dll и WebView2Loader.dll.

Соберите проект (Build) и запустите (F9).
